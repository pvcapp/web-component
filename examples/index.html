PVC Component - Ví dụ

Các trang dưới đây minh họa giao diện component. API công khai hiện có gồm Button, Form field, datePicker, Alert, Toast, divChe, Loading và Dashboard card; xem phạm vi API trước khi tích hợp.

  • Button
  • Form, field và date picker
  • Alert
  • Dashboard: card, desk card, table
  • Loading: bar, screen, text
  • Toast
  • divChe: màn che toàn trang
  • Tiện ích: overlay và chat line
